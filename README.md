## 預計交付與已實作功能

1. **品牌首頁與行動優先響應式導覽**
   - 品牌名稱、核心視覺、首屏主標與核心賣點、雙行動呼籲按鈕（「看商品」與「認識品牌」）。
   - 完整品牌故事、安全檢驗承諾（標記示例檢驗標準）、聯絡資訊（標記示例）與頁尾。
   - 手機版可展開／收合之漢堡選單，支援鍵盤與 `Esc` 關閉。
2. **本地商品型錄、即時搜尋與分類篩選（`js/data.js`）**
   - 7 款攝影棚等級本地商品圖片與資料，涵蓋四大分類：`嗅聞益智`、`天然耐咬`、`互動逗趣`、`送禮組盒`。
   - 支援「分類按鈕篩選」＋「即時關鍵字搜尋」同時組合使用，並具備友善無結果提示與一鍵重設。
   - 每個商品卡提供「查看詳情」，以無障礙彈窗顯示完整介紹與安全材質說明，支援 `Esc` 與點擊背景關閉，並以 `textContent` 安全渲染所有文字。
3. **限時禮遇倒數橫幅、顧客評價與 FAQ**
   - 採用固定台灣時區（`+08:00`）截止時間的即時倒數計時器，顯示「天、時、分、秒」與活動結束狀態。
   - 提供活動優惠碼（`MORIPAW88`）一鍵複製與即時操作回饋，並可與預購清單折扣連動。
   - 從 `js/data.js` 載入顧客評價（標記為示例）與 4 則鍵盤可展開常見問題（FAQ）。
4. **預購清單與 LINE / IG 貼上專用明細**
   - 支援加入預購、增減數量、移除商品、即時計算小計、優惠折扣與預購總額。
   - 以瀏覽器 `localStorage` 自動保存商品 ID 與數量。
   - 提供「聯絡人暱稱」與「送禮／毛孩備註」欄位，空清單或空白暱稱皆有清楚行內提示。
   - 產生格式化純文字明細（品項、數量、金額、優惠碼），支援「複製明細」與「下載 `.txt`」，方便顧客直接貼給品牌 LINE 官方帳號或 Instagram 小盒子。

本網站為純原生靜態網站，可透過下列任一方式於本機開啟預覽（建議透過本機 HTTP 伺服器預覽以確保所有功能與路徑行為與線上一致）：

   ```powershell
   npx serve .
   ```

## GitHub 與 Vercel 靜態部署指南

本專案完全由原生靜態檔案組成，無須建置步驟（Build Step）即可直接部署至 Vercel。

### 一、從 GitHub 匯入 Vercel 操作步驟
1. 將專案推送至您的 GitHub Repository（建議包含本清單所有檔案，勿包含 `.DS_Store` 或個人編輯器設定）。
2. 登入 [Vercel Dashboard](https://vercel.com/)，點擊 **Add New... → Project**。
3. 選擇您剛建立的 GitHub Repository 並點擊 **Import**。
4. 在 **Configure Project** 畫面確認以下設定：
   - **Framework Preset**：選擇 **`Other`**（純靜態 HTML 網站）。
   - **Root Directory**：維持預設 **`./`**（根目錄即包含 `index.html`）。
   - **Build and Output Settings**：保持關閉（不填寫 Build Command，Output Directory 留空或維持預設，由根目錄直接輸出靜態檔案）。
   - **Environment Variables**：無需設定任何環境變數（本網站不使用後端或金鑰）。
5. 點擊 **Deploy**，等待數十秒完成部署。

### 二、為何加入 `vercel.json` 與設定說明
本專案包含多張高解析度攝影棚產品圖片與本地樣式／腳本，因此加入極簡的 `vercel.json` 為靜態資源設定自訂快取標頭：
- `/images/(.*)`：設定 `Cache-Control: public, max-age=86400, stale-while-revalidate=604800`，讓商品圖片在瀏覽器與邊緣節點可重複快取，加速再次造訪載入。
- `/css/(.*)` 與 `/js/(.*)`：設定 `Cache-Control: public, max-age=3600, must-revalidate`，兼顧效能與更新即時性。
- 安全標頭：`X-Content-Type-Options: nosniff` 防止 MIME 類型嗅探。

### 三、Vercel 介面與部署後確認清單
- [ ] **Framework Preset** 確認為 `Other`，未誤選 Vite 或 Next.js。
- [ ] **Root Directory** 指向包含 `index.html` 的專案根目錄。
- [ ] **Deployment Status** 顯示 `Ready`，且無 404 資源錯誤（開啟瀏覽器 DevTools → Network 檢查所有 `images/*.jpg`、`css/style.css`、`js/data.js`、`js/app.js` 皆回傳 HTTP `200`）。
- [ ] **大小寫一致性**：確認所有圖片在 Linux 環境下都能正常顯示。
- [ ] **Domains**：確認產生的 `.vercel.app` 網址可正常於手機與電腦開啟，並將正式網址補回本 `README.md` 與 `index.html` 的 Open Graph 標籤。

## 人工驗收測試步驟

### 1. 手機導覽測試
1. 將瀏覽器切換至手機寬度（如 `375px`）或使用實體手機開啟。
2. 點擊右上角漢堡選單鈕，確認選單順暢展開且焦點指示清晰。
3. 使用鍵盤 `Tab` 移動至選單內項目並按 `Enter` 跳轉至對應區塊，確認跳轉後選單自動收合；再次開啟後按 `Esc`，確認選單關閉且焦點回到選單按鈕。

### 2. 商品搜尋與分類篩選測試
1. 依序切換「全部」、「嗅聞益智」、「天然耐咬」、「互動逗趣」、「送禮組盒」，確認顯示對應數量商品。
2. 在搜尋框輸入關鍵字（如「木」、「禮盒」、「羊」），確認商品列表即時更新，且可與目前選取的分類篩選同時疊加運作。
3. 輸入不存在的關鍵字（如 `zzzz`），確認出現友善無結果提示與「重設篩選」按鈕，點擊後恢復全部商品。

### 3. 商品詳情彈窗測試
1. 點擊任一商品卡的「查看詳情」，確認彈窗正確顯示商品圖、分類、價格、完整介紹與安全材質說明。
2. 按鍵盤 `Esc` 關閉彈窗；再次開啟後點擊半透明深色背景遮罩，確認亦可關閉。
3. 於彈窗內點擊「加入預購清單」，確認預購數量更新且畫面給予提示。

### 4. 限時活動倒數測試（進行中 vs 已過期）
- **進行中狀態**：`js/data.js` 預設活動截止時間為 `2026-12-31T23:59:59+08:00`（台灣時間），開啟頁面應即時顯示天、時、分、秒倒數，且「複製優惠碼」按鈕可正常複製 `MORIPAW88` 並顯示「已複製優惠碼」。
- **已過期狀態驗收**：暫時將 `js/data.js` 中的 `CAMPAIGN_CONFIG.endTime` 改為過去時間（例如 `2025-01-01T00:00:00+08:00`）並重新整理頁面，確認倒數顯示 `00 天 00 時 00 分 00 秒` 與「本檔禮遇活動已結束」標籤，且預購區提示該優惠碼已失效（驗收完記得改回未來時間）。

### 5. 預購明細與持久化測試
1. 加入 2 項以上商品，測試 `+` / `-` 增減數量與「移除」功能，確認小計、優惠折扣與預購總額即時重算。
2. 重新整理瀏覽器頁面，確認預購清單品項與數量透過 `localStorage` 完整保留。
3. 不填寫「聯絡人暱稱」或清空商品後點擊「複製明細」／「下載 .txt」，確認不彈出 `alert()`，改以頁面上親切的紅／琥珀色文字提示使用者補全。
4. 填寫暱稱與備註後點擊「複製明細」，貼到記事本確認品項、數量、金額與優惠碼排版整齊；點擊「下載 `.txt`」，確認瀏覽器下載可開啟的純文字檔。

### 6. 社群分享預覽測試
1. 於正式網址上線並將 `index.html` 中 `og:url` 與 `og:image` 補齊為完整 `https://` 網址後，將連結貼入 LINE 聊天室或使用 Facebook Sharing Debugger / OpenGraph 預覽工具測試。
2. 確認縮圖正確顯示品牌主視覺、標題顯示「毛森禮研所 MoriPaw Atelier — 絕對安全好玩的高端寵物送禮選物」，描述文字完整無亂碼。
